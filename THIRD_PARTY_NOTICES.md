# Avisos de tercers — paquet font 1.0.1

Aquest paquet acompanya el runtime de Lletrium! 1.0.1. La llicència GPL de l’arrel només cobreix els materials propis identificats a `LICENSING.md`; no canvia les condicions dels recursos de tercers.

Els avisos detallats i les llicències incorporades es troben a `build/extension/licenses/THIRD_PARTY_NOTICES.md` i les seves subcarpetes. Els snapshots de referència i els manifests de procedència són a `references/`, `analysis/reference-oracle/`, `engine-src/resources/` i `build/extension/build/resources/`.

Els paquets `.pack` de català, espanyol, anglès i francès es publiquen separadament a la branca GitHub `language-packs`; no s’inclouen aquí. Les seves llicències i avisos també s’han de distribuir amb cada paquet. El mapa francès inclòs a `build/extension/licenses/french-data/RESOURCE-MAP.md` assenyala diverses fonts amb termes o lineage encara no resolts. El catàleg de la branca no substitueix aquesta revisió. No es declara que tots els recursos francesos tinguin els drets de redistribució confirmats.

Els avisos de LanguageTool, Softcatalà/catalan-dict-tools, Morfologik, OpenNLP i les altres fonts es conserven a l’inventari detallat. No s’ha de deduir una llicència per proximitat: prevalen els avisos i manifests del recurs concret.
