# French runtime resources

These files are maintained here as the source inputs for the proof-stage French runtime. `engine-src/build.mjs` stages them into `build/extension/` together with the French adapters from `engine-src/modules/french/`.

The provenance and redistribution terms for several French resources are still pending. No license is inferred from the LanguageTool code license or from the fact that a resource is present in this source tree. See `build/extension/licenses/french-data/RESOURCE-MAP.md` for the itemized status and keep that status pending until the unresolved sources are verified.
