# Requisits abans de publicar la versió 1.0.0

Aquest fitxer acompanya el paquet de desenvolupament; no és una declaració d'assessorament jurídic ni acredita drets que no constin a les fonts.

La còpia de fonts preparada per publicar amb GPL inclou `LICENSE`, `LICENSING.md` i l'inventari arrel de tercers. Si la publiques amb l'extensió, distribueix-la des del mateix lloc i conserva els avisos de cada component upstream. Aquesta variant no substitueix ni elimina les llicències pròpies de les fonts i dades originals de tercers.

- Publica al costat de la extensio GPL el paquet `Corrector-Catala-1.0.0-source-GPL-3.0-or-later.zip` o una copia publica equivalent. Inclou les fonts, llicencies, avisos i scripts aplicables; conserva intacte el ZIP de fonts original com a copia anterior sense la llicencia global.
- Publica `PRIVACY.md` en una pàgina web accessible i posa l'URL a la fitxa i als camps de privacitat de Chrome Web Store. El responsable i el contacte ja consten al document; completa també les declaracions del tauler amb el comportament real de l'extensió.
- El desenvolupador declara que el codi restant és treball original creat durant aquest projecte amb assistència de ChatGPT. OpenAI assigna a l'usuari els drets sobre les sortides entre les parts, en la mesura que ho permeti la llei aplicable; això no valida entrades de tercers ni fragments copiats. Mantén l'inventari de LanguageTool, Softcatalà/catalan-dict-tools i Morfologik; si apareix cap altre codi o dada de tercers, identifica'n l'origen i els termes abans de publicar.
- Com que els fitxers de LanguageTool i Softcatalà provenen de repositoris/artefactes de tercers, la distribució conserva les fonts auditades, els hashes i els avisos. Si es detecta cap codi importat d'un altre repositori de GitHub que no aparegui a l'inventari, cal identificar-ne l'origen i els termes abans de publicar.
- El ZIP de fonts inclou els scripts de construcció seleccionats, els recursos empaquetats i les entrades declarades pels manifests. Verifica abans de publicar que cada recurs llicenciat LGPL tingui font corresponent i que els scripts/inputs que permeten modificar-lo estiguin disponibles. El paquet no afirma una reconstrucció bit a bit de tota l'extensió.
- Comprova que la descripció, els permisos i les declaracions de privacitat de la fitxa coincideixen amb el comportament real de l'extensió.

La versió 1.0.0 conserva els avisos de LanguageTool i Softcatalà i les còpies de les llicències LGPL/GPL. Els ZIP de referència de LanguageTool i catalan-dict-tools no fixen un commit de Git; el projecte conserva els SHA-256 dels arxius auditats a `references/upstream.lock.json`.
