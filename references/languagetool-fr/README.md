# LanguageTool French source reference

This is the selected French language-module `src/main` tree and its module POM from the user-supplied LanguageTool 6.9-SNAPSHOT archive. The archive SHA-256 is recorded in `SOURCE-MANIFEST.json`; the archive did not provide an immutable Git revision. These files are retained for source comparison and provenance review. They are not automatically compiled into Lletrium's runtime.

The adapted French runtime files are currently delivered under `build/extension/src/french-*.js`, with French resources under `build/extension/build/resources/fr/`. `engine-src/build.mjs` does not yet generate or integrate the French pipeline. Do not treat this reference snapshot as proof that every upstream data resource is cleared for redistribution. Resource-by-resource unresolved rights and provenance are tracked in `build/extension/licenses/french-data/RESOURCE-MAP.md`; those items remain pending.

LanguageTool's `COPYING.txt` and module POM are included. Preserve upstream notices and applicable terms when using this source.
