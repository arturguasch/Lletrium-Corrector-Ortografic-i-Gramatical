# French pack: attribution and distribution status

The French pack is staged for the next compatible Lletrium build (minimum extension version 1.0.1). Its payload and each embedded resource hash were verified against the experimental candidate.

Attribution for some individual resources is still pending identification, and the exact upstream lineage of `fr.sor` remains unconfirmed. The project has chosen to retain those resources with an explicit pending-attribution notice. This note records provenance status; it does not claim that every resource has an independently verified license or that the files have been altered to change their license.

See `RESOURCE-MAP.md`, `README_fr.txt`, `README_lexique.txt`, `french-pos-dict-0.7.pom`, and `NOTICE-numbertext-fr-sor.md` for source and license evidence currently available. Revisit this notice if an upstream author or LanguageTool supplies additional attribution or terms.
