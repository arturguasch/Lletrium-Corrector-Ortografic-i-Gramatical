# German pack resource notices

The stable German 1.0.2 pack contains separate resources with separate upstream licenses; no single license covers the whole pack. Per-resource, source-export, and license hashes are in german-source-provenance.json.

- german.dict.gz, german_synth.dict.gz, and german_tags.txt.gz are from de.danielnaber:german-pos-dict:1.2.4, CC BY-SA 4.0, with data attributed upstream to Morphy and extensions/corrections by Julian von Heyl. Attribution: https://github.com/languagetool-org/german-pos-dict. License: https://creativecommons.org/licenses/by-sa/4.0/. The analysis-only JAR is not redistributed.
- de_DE.dict.gz, de_AT.dict.gz, and de_CH.dict.gz are LanguageTool Morfologik dictionaries whose upstream notices identify GPLv2/v3 terms. The exact word+frequency sequences from all three binaries are exported as UTF-8 source under source/morfologik/*.source.txt.gz with their .info files. The export was round-tripped with Morfologik 2.2.0 / CFSA2 and preserved entry count/content hashes. Thus the GPL dictionary source representation accompanies this published pack; the original regional .aff/.dic inputs, notices, and create_dict.sh are also retained under source/hunspell/.
- LanguageTool's build recipe also references Jan Schreiber's public-domain list at SourceForge r2187 and Mozilla Gaia German frequency data (Apache-2.0). Historical upstream inputs are cited for attribution: SourceForge German dictionary code revision r2187 (https://sourceforge.net/p/germandict/code/HEAD/tree/) and archived Mozilla Gaia German keyboard frequency data (https://github.com/mozilla-b2g/gaia/tree/master/apps/keyboard/js/imes/latin/dictionaries). Their original revisions are not needed to rebuild these exact exported sequences. The Apache license and attribution notice are included.
- addedCompound.txt.gz and multitoken-suggest.txt.gz are LanguageTool resources; their uncompressed source text is under source/. LanguageTool's LGPL-2.1-or-later notice is included.

The inspected LanguageTool checkout is 6.9-SNAPSHOT, with no exposed Git HEAD. Resource, source-export, and license hashes are recorded in german-source-provenance.json. To rebuild an exported FSA sequence file with the same Morfologik toolchain, decompress the profile source text and run morfologik.tools.FSACompile with --exit false, -i <profile>.source.txt, -o <profile>.dict, and -f CFSA2; keep the matching .info beside it. Compare the rebuilt dictionary by enumerating its entries, since serializer output bytes can differ while the ordered word+frequency sequences remain identical. LanguageTool master uses this FSACompile command shape and CFSA2 format. Keep this notice, all license texts, source exports, original inputs, and hashes with the stable catalog entry.
